## Git Commits

- **NEVER** add "Co-authored-by:" or any co-author lines
- **Format:** `[<branch>] <summary>` (e.g. `[T-67] Add credit wallet segmented progress bar`)
- Use current branch name (e.g., `T-XX`), sentence case, active voice, ~80 chars max

## Purpose
- Keep changes small, targeted, and consistent with the existing codebase.
- Make debugging systematic: gather evidence first, then apply the smallest fix that addresses the root cause.
